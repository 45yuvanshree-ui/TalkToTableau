# TalkToTableau

## TalkToTableau: An Agentic Business Intelligence Framework for Text-to-SQL, Visual Analytics, and Data Storytelling

TalkToTableau is a conversational Business Intelligence system designed to allow users to ask business questions using natural language and receive evidence-based analytical answers.

## Project Goals

The system will support:

- Natural-language business questions
- Text-to-SQL
- PostgreSQL data
- CSV files
- Excel files
- Analytical workflows
- Evidence verification
- Visualization
- Data storytelling
- Multi-turn conversation
- Adaptive LLM routing
- Guardrails
- Application tracing
- Evaluation

## Architecture

The system will use exactly three primary AI agents:

1. Business Analyst
2. Insight + Evidence Verification
3. Data Storytelling

Deterministic operations such as SQL validation, analysis, visualization, and data access will remain workflows or infrastructure components rather than additional agents.
